# Somya Sharma – Portfolio

Static website (no build step). Files:
- index.html – the whole site
- profile.jpg – profile photo
- resume.pdf – resume used by the Download resume button

## 1. Make the contact form deliver to Gmail
1. Go to https://web3forms.com and enter somay3112@gmail.com to get a free Access Key (it arrives by email).
2. Open index.html, find YOUR_WEB3FORMS_ACCESS_KEY and replace it with your key.
3. Save. Messages from the form will now arrive in your inbox.

## 2. Deploy on Vercel
Option A (easiest): vercel.com > Add New > Project > drag and drop this folder.
Option B: push this folder to a GitHub repo, then import the repo in Vercel. Framework preset: Other. Leave build settings empty.

## 3. After deploying
Replace the GitHub link if needed (currently github.com/somay12) and add more projects in the Projects section of index.html.
